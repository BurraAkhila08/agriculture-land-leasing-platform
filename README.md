# agriculture-land-leasing-platform
A full-stack Agriculture Land Leasing Platform that connects landowners and farmers for seamless land leasing. Features include user authentication, land listings, search and filtering, lease booking with conflict checking, messaging, and payment management. Built using Node.js, Express.js, MySQL, HTML, CSS, JavaScript, and Bootstrap.
# Agriculture Land Leasing Platform

A full-stack web application that connects landowners and farmers, making agricultural land leasing simple, transparent, and accessible.

## Features
- User Registration and Login
- JWT Authentication
- Land Listing Management
- Search and Filter Lands
- Lease Booking with Conflict Checking
- Communication Interface
- Payment Management
- Reviews and Ratings

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Authentication
- JSON Web Token (JWT)

## Project Objective
To provide a secure and user-friendly platform where landowners can list agricultural land and farmers can easily find and lease suitable land.
